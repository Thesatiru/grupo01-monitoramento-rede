# Distributed Monitoring and Performance Analysis System for the University Network

**Group 01 – Campus network monitoring** · Fatec Ferraz de Vasconcelos · Integrated Project (Computer Networks, Distributed Systems and English)

## Overview
A prototype that periodically checks devices on a campus network using ICMP (ping), measures availability, latency and packet loss, stores the results in a central service and shows them on a dashboard.
